How to Use This Project

Install

Use Python 3.11 or 3.12 and poetry install --with dev.

Diagnose

Run poetry run python scripts/project.py doctor.

Validate

Run project.py test, lint, and typecheck inside your Poetry environment.

Operate

Use authenticated operator flows; no shortcut grants live authority.
